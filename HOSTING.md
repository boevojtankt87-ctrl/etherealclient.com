# Хостинг общей базы (чтобы друг видел регистрацию)

Сейчас сайт на GitHub Pages работает в локальном режиме: у каждого
своя база в браузере. Чтобы база стала ОБЩЕЙ для всех, подними
`server.py` на бесплатном хостинге и укажи его адрес в конфиге.

## Вариант: Koyeb (бесплатно, без карты)

1. Репозиторий уже готов: в корне лежат `Procfile` и папка `server/`.
2. Зарегистрируйся на koyeb.com через GitHub.
3. Create App → выбери репозиторий `etherealclient.com`.
4. Builder: **Buildpack**, Run command: `python server/server.py`.
   Порт подхватится сам (сервер читает `PORT` из окружения).
5. Дождись деплоя, скопируй адрес вида `https://xxx.koyeb.app`.

## Подключение сайта к базе

1. Открой `website/js/config.js`, вставь адрес:
   `API_BASE: 'https://xxx.koyeb.app'`
2. Закоммить и запушь — Pages обновится за пару минут.
3. Проверка: зарегистрируйся сам, попроси друга зарегаться —
   теперь ты увидишь его в админке, а он тебя в IRC.

То же самое в лаунчере: Настройки → адрес сервера → тот же URL.

## Важно про бесплатный хостинг

SQLite-файл живёт на диске контейнера: при перезапуске/редеплое
база может обнулиться (бесплатные тарифы не держат диск).
Для продакшена следующий шаг — переезд на бесплатный Postgres
(Supabase), скажи когда — сделаю миграцию.
Локальный `start.bat` этой проблемы не имеет: файл рядом, ничего не трется.
