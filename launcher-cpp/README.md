# Ethereal Launcher (C++)

Полноценный лаунчер без официального лаунчера Майнкрафта и без Java:
сам качает Java 21, клиент 1.21.11, библиотеки, ассеты, Fabric и мод
с GitHub — и запускает игру напрямую.

- Безрамочное окно, весь интерфейс рисуется вручную (GDI, 60 fps)
- Вход и восстановление пароля через API сайта
- HWID привязывается только при первом запуске под своим логином
- RAM-слайдер 1–16 ГБ, новости из журнала обновлений
- Иконка и метаданные встроены в exe

## Сборка локально (MinGW-w64)

```
website/launcher-cpp/build.bat
```

## Сборка в CI

Пуш с изменениями в `launcher-cpp/` собирает exe в Actions
(артефакт `EtherealLauncher-win64`). Тег вида `cpp-v1.0`
создаёт GitHub Release с exe автоматически.
