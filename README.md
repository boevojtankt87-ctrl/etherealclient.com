# Etherial Client — сайт + база данных

Сайт работает через свой backend: SQLite-база (`server/etherial.db`)
и JSON API (`server/server.py`, только стандартная библиотека Python).
Ничего ставить не нужно.

## Запуск

Двойной клик по `start.bat` или вручную:

```
cd website
python server/server.py
```

Открыть: http://localhost:8000

## Деплой на GitHub Pages

Pages отдаёт только статику, поэтому фронт двурежимный:

- рядом запущен `server.py` → сайт работает с общей SQLite-базой;
- сервера нет (как на Pages) → сайт сам переключается на локальное
  демо-хранилище в браузере (`js/store.local.js`, тот же интерфейс).

Код один, ничего переключать не нужно. Для публикации:

1. Залей **содержимое папки `website/`** в корень репозитория
   (`index.html`, `cabinet.html`, `market.html`, `css/`, `js/`, `assets/`).
2. В настройках репозитория: Settings → Pages → Deploy from a branch,
   ветка main, папка `/ (root)`.
3. Через минуту сайт живёт на `https://ТВОЙ-НИК.github.io/РЕПО/`.

Файл `.nojekyll` уже лежит — Pages не будет резать служебные файлы.
На Pages у каждого посетителя своя локальная база (общая — только
со своим сервером).

## Общий хостинг (PHP, Timeweb)

На обычном хостинге с PHP работает `api.php` — весь JSON API без Python:

1. Залить в `public_html`: `index.html`, `cabinet.html`, `market.html`,
   `css/`, `js/`, `assets/`, `files/`, `api.php`, `.htaccess`.
2. `.htaccess` роутит `/api/*` → `api.php` и запрещает папку `data/`.
3. База — SQLite в `data/etherial.db`, создаётся сама при первом запросе
   (нужна запись в папку; если её нет — положи `config.php` с `$MYSQL`).
4. Фронт сам детектит API (`/api/stats`) и работает с общей базой;
   если API не отвечает — переключается на локальное демо в браузере.
5. Админ по-прежнему только `zxs`.

## Структура

- `index.html` — лендинг: hero, преимущества, статистика, витрина, FAQ, контакты
- `cabinet.html` — кабинет: Главная / IRC / Настройки / Админ
- `css/` — base, landing, cabinet (один шрифт Inter везде)
- `js/store.js` — API-клиент (fetch + токен сессии)
- `js/config.js` — дата обновления, ссылки на Discord / Telegram / YouTube
- `js/common.js` — тема оформления, шапка, тосты
- `js/landing.js`, `js/cabinet.js` — логика страниц
- `server/db.py` — SQLite: users, sessions, keys, chat, logs
- `server/server.py` — статика + API
- `start.bat` — запуск в один клик

## База данных

Таблицы: `users` (uid, nick, email, pass-хэш pbkdf2, role, hwid, sub_until, plan),
`sessions` (токены + last_seen для онлайна),
`keys` (ключи ETHR-XXXX-XXXX), `cards` (хэши карт → UID), `builds` (чейнджлог),
`polls` + `votes` (голосования), `chat`, `logs`. Никаких фейковых данных:
статистика и онлайн считаются по базе, чат изначально пуст.

- UID порядковый: первый — 1, второй — 2 и т.д.
- Ник `zxs`, зарегистрированный первым, получает UID 1 и роль `admin`.
- Почта обязательна при регистрации, по ней восстанавливается пароль
  (ник + почта → новый пароль, сессии сбрасываются).
- Сессия: галочка «Запомнить меня» — токен в localStorage (навсегда)
  или sessionStorage (до закрытия вкладки).
- Роли: `user`, `tester`, `youtube`, `tiktok`, `moderator`, `admin` (выдача во вкладке Админ).

## Чего нет у других

- Журнал обновлений: админ публикует билды из кабинета, лента на главной.
- Голосования: админ запускает опрос, владельцы голосуют в кабинете
  (один голос), результаты live на главной.
- Маркет конфигов: игроки выставляют пресеты, оплата с баланса,
  продавцу 90%. Текст конфига открывается только после покупки.
- Шесть тем сайта: Etherial Dark, Mono, Crimson, Toxic, Royal, Arctic + свой акцент.

- Подписка 30 дней — 300₽
- Подписка 90 дней — 550₽
- Подписка 180 дней — 800₽
- Сброс HWID — 150₽ (в кабинете)

Оплата: номер карты + срок + CVC с проверкой Луна, на сервер уходит
только SHA-256 хэш номера. Одна карта привязывается к одному UID навсегда —
оплата второго аккаунта той же картой блокируется. Демо-карта: 4242 4242 4242 4242.
